# Research Artifacts

This folder stores architectural research artifacts that inform platform governance and future implementation planning.

Reverse engineering artifacts, when available, should be stored here rather than mixed with governed architecture, data product, or intelligence documentation.

Current research artifact groups include:

- 010A Executive Warehouse Reverse Engineering
- 010B Executive Pipeline Reverse Engineering

These artifacts are research inputs only. They do not define platform contracts unless promoted through governed architecture, Certified Data Product, or decision documentation.
